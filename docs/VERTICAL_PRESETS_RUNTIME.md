# Leads Desk Vertical Presets Runtime

## Available Presets

- General Business
- Real Estate
- Insurance
- Travel / Education Agency
- Service Business
- Training / Coaching
- Healthcare / Clinic
- Legal / Professional Services

## What A Preset Applies

Presets can provide:

- default lead stages
- default lead sources
- recommended custom fields
- lead preview defaults
- dashboard widget defaults

## Safety Rules

- applying a preset does not hard delete existing configuration
- preset application can be limited to missing defaults
- existing custom fields are preserved unless a user explicitly changes them later
- archived-first behavior remains the standard

## Runtime Route

- `/admin/settings/industry`
