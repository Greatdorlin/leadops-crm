# Leads Desk Dashboard Customization

## Purpose

Dashboard customization lets owner and admin tune the dashboard to the sales priorities of a client workspace.

## Supported Controls

- widget visibility
- widget order
- default dashboard period preference
- reset to defaults

## Widget Set

- Total Leads
- New Leads
- Leads This Month
- Overdue Follow-ups
- Pipeline Value
- Won Value
- Conversion Rate
- Top Sources
- Recent Intake
- Team Performance
- Target Progress
- My Tasks

## Current Runtime Scope

- the dashboard reads saved widget visibility and order
- task and performance sections respect the saved widget set
- sales calculations remain unchanged
- write paths are unaffected

## Runtime Route

- `/admin/settings/dashboard`
