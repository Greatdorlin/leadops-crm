# Leads Desk Brand Customization

## What Can Be Branded

From `Settings -> Appearance`, owner and admin can control:

- company name
- logo URL
- light-mode logo URL
- dark-mode logo URL
- favicon URL
- login logo URL
- light-mode login logo URL
- dark-mode login logo URL
- login background URL
- login headline
- login subheadline
- color system
- font preset
- radius and density
- design style and liquid glass behavior
- celebration preferences for milestones and targets

## Safe Defaults

- company name defaults to `Leads Desk`
- login headline defaults to `Welcome back`
- login subheadline defaults to `Manage leads, follow-ups, and sales performance in one private workspace.`
- if only one logo is provided, Leads Desk reuses it across light and dark surfaces
- if both logo variants are provided, Leads Desk automatically prefers the matching logo for the surface

## What Is Not Editable In-App

- `DATABASE_URL`
- auth secrets
- OAuth provider secrets
- deployment domains
- server-level email delivery configuration

## Buyer Demo Tip

Before a demo, set:

- company name
- logo URL
- dark-mode logo URL for the sidebar
- primary color
- sidebar color
- login background
- celebration toggles if you want a more energetic dashboard reveal

That gives the fastest visible shift from generic workspace to client-ready product.
