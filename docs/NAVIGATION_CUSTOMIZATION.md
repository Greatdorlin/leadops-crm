# Leads Desk Navigation Customization

## Purpose

Navigation customization allows owner and admin to make the sidebar feel closer to the client workflow without breaking critical routes.

## What Can Change

- item label
- item visibility
- item order

## Guardrails

- `Dashboard`, `Leads`, and `Settings` remain visible
- hidden menu items do not weaken permission enforcement
- customization affects navigation display, not backend authorization

## Runtime Route

- `/admin/settings/navigation`
