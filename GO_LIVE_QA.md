# Leads Desk Go-Live QA Checklist

Use this checklist before approving a client deployment as production-ready.

1. Login as owner/admin.
2. Create a lead field.
3. Add a select field with options.
4. Add a manual lead with custom fields.
5. View lead details.
6. Edit custom field values.
7. Show a custom field in the table.
8. Export leads and verify custom field columns.
9. Import leads with custom field columns.
10. Create a form source.
11. Add mappings.
12. Send a webhook test.
13. Confirm a lead is created.
14. Confirm custom values are saved.
15. Confirm the intake event is logged.
16. Confirm a failed webhook logs an error.
17. Assign a lead.
18. Set a follow-up.
19. Verify overdue state.
20. Mark a lead won or lost.
21. Check dashboard metrics.
22. Check reports.
23. Check notifications.
24. Check production environment docs.
25. Build the Docker image.
26. Run `docker compose` locally or in staging.
27. Back up the database.
28. Restore the database in a test environment.
