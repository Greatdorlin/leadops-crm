# Leads Desk Client Handover

## Delivery Summary

This client receives a private Leads Desk workspace for their business.

## Provide To The Client

- admin URL
- login instructions
- owner/admin contact account
- high-level feature summary
- backup responsibility agreement
- support contact and response expectations

## Login Instruction

- Sign in with the approved Google account configured for the workspace.
- If domain restrictions are enabled, use an allowed company domain.
- Keep owner/admin access limited to trusted operators.

## What The Client Owns

- their lead data
- exported data files
- stage/source/custom-field configuration
- the business process they run inside the workspace

## What Support Usually Covers

- deployment and environment setup
- OAuth configuration guidance
- schema updates and releases
- bug fixes
- configuration assistance for custom fields, form sources, and mappings

## What Is Usually Excluded

- new third-party ad-platform integrations not already included
- custom workflow automation beyond the agreed scope
- unmanaged hosting costs
- end-user device support

## Backup Responsibility

Agree clearly who owns:

- daily backups
- restore testing
- infrastructure updates
- SSL renewal if not automated by the hosting platform

## Renewal Or Support Note

If ongoing maintenance is part of the commercial agreement, document:

- support window
- update policy
- incident escalation path
- infrastructure billing responsibility
