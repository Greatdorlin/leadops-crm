# Third-party notices

Leads Desk includes third-party software. Preserve each dependency's licence and copyright notices when distributing source, installers or container images. The release review produces a CycloneDX inventory from package-lock.json and a collected-licence bundle; neither replaces the actual licence terms or a distribution-specific review.

## Included fonts

- Manrope: Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope). SIL Open Font License 1.1. Licence: public/fonts/Manrope-OFL.txt.
- Barlow Condensed: Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow). SIL Open Font License 1.1. Licence: public/fonts/BarlowCondensed-OFL.txt.

These copyright and licence references were read from the bundled font metadata. Exact upstream binary correspondence still requires provenance confirmation. Keep the full OFL texts with distributed font files, and review reserved names before modifying fonts.

## Distribution review

The lockfile includes LGPL libvips/native sharp variants, MPL packages, and a CC-BY data package across supported development/build platforms. Identify which files enter the actual installer or container. Retain applicable notices and source/relinking rights before distribution; development-only classification does not waive obligations if tooling is shipped.

A package offering a choice of licences may permit one option to be selected; record that decision rather than treating every offered licence as simultaneously mandatory. Missing or ambiguous package metadata requires checking upstream licence files. The confidential release review records unresolved packages and binary-platform coverage.

Commercial installation and source transfer terms must preserve upstream rights. Legal review is still needed for the final distribution model and provenance documents.
